## ✏️ Sobre o repositório

Este repositório foi criado para **organizar projetos práticos** de backend desenvolvidos como parte de desafios técnicos aplicados por empresas durante processos seletivos.

Os projetos têm como foco:

- Boas práticas de desenvolvimento
- Organização de código
- Integração com bancos de dados
- Testes básicos (quando aplicável)

---

## ⚙️ Tecnologias utilizadas

Dependendo do desafio, foram utilizadas algumas das seguintes tecnologias e ferramentas:

- **Java / Spring Boot**
- **Node.js / Express.js**
- **Banco de dados relacionais** (MySQL, PostgreSQL)
- **Postman** (documentação e testes de APIs)
- **JUnit / Jest** (para testes automatizados)
- **Swagger** (documentação interativa de APIs)

## 📂 Projetos incluídos

Abaixo alguns exemplos de projetos presentes neste repositório:

| Projeto | Descrição | Tecnologias |
|--------|-----------|-------------|
| **loans-challenge** | Implementa um serviço que determine quais modalidades de empréstimo uma pessoa tem acesso. | Java, Spring Boot, JPA, H2 |
| **nubank-challenge** | API REST para gerenciamento de cleinte e seus contatos. | Java, Spring Boot, JPA, H2, Postgres |
| **points-of-interest** | API REST para mostrar ponto de interesse por GPS. | Java, Spring Boot, JPA, H2 |
| **secure-password** | Serviço de validação de senha. | Java, Spring Boot, JPA, H2 |
| **url-shortener** | Serviço para encurtar URLs. | Java, Spring Boot, JPA, H2 |
